## 1. ใช้งานหน้า admin

เข้าสู่ระบบด้วย**ชื่อผู้ใช้และรหัสผ่าน** (ใช้ได้หลายคน ดู[ผู้ใช้และรหัสผ่าน](#4-ผู้ใช้และรหัสผ่าน)) อยู่ได้ 6 ชั่วโมงแล้วต้องเข้าใหม่

### เมนู
- **มือถือ:** แถบล่าง 4 ปุ่ม `รายการสินค้า` (หน้าแรก) · `สรุป` · `นำเข้า` · `ตั้งค่า` (ไอคอนเฟือง)
- **คอมพิวเตอร์:** แท็บด้านบน `รายการสินค้า` · `สรุป` · `นำเข้า CSV` · `ตั้งค่า`

### เพิ่มสินค้า
1. ในหน้า **รายการสินค้า** กดปุ่ม **เพิ่มสินค้า** (มุมขวาบน) — บนคอมพิวเตอร์ฟอร์มเปิดเป็นแผงด้านขวา บนมือถือเปิดเป็นหน้าเต็มที่มี "รายการสินค้า › เพิ่มสินค้า" ด้านบน (กดเพื่อย้อนกลับ) → กรอก **รหัสสินค้า** (A-Z a-z 0-9 - _ ไม่เกิน 40 ตัว ห้ามซ้ำ) และ **ชื่อสินค้า**
2. เลือก **หมวดหมู่** จากรายการ หรือเลือก "+ เพิ่มหมวดใหม่…" แล้วพิมพ์ชื่อ
3. ใส่ **รายละเอียด** (ข้อความธรรมดา ขึ้นบรรทัดใหม่ได้)
4. กด **เลือกรูป** เลือกได้หลายรูปพร้อมกัน ระบบ**ย่อรูปให้เอง** (ด้านยาวไม่เกิน 1600px) และเรียงตามชื่อไฟล์ 
   - **รูปปกในรายการสินค้า** (หน้า admin) คือ**รูปล่าสุด**ที่เพิ่มเข้ามาโดยอัตโนมัติ ถ้าอยากใช้รูปอื่น ให้เปิดหน้าแก้ไขสินค้าแล้วกด **ดาว** ที่รูปนั้น (รูปที่เลือกเองจะไม่เปลี่ยนเมื่ออัปโหลดรูปใหม่ กด "ใช้รูปล่าสุดอัตโนมัติ" เพื่อกลับไปแบบเดิม)
   - **หน้าลูกค้า**แสดงรูปปกเป็น**รูปแรก**ของแกลเลอรี และใช้เป็น**รูปพรีวิวใน LINE** ที่เลือกไว้ รูปที่เหลือเรียงตามชื่อไฟล์ (เปลี่ยนรูปปกแล้วหน้าร้านอัปเดตภายในประมาณ 1 นาที ส่วนลิงก์ที่เคยส่งใน LINE แล้วอาจยังโชว์รูปเดิม ดู[หัวข้อ 3](#ถ้า-line-ยังโชว์พรีวิวเก่า))
5. กด **บันทึกสินค้า**

> **เรียงรูป:** ตั้งชื่อไฟล์เป็น `1.jpg`, `2.jpg`, `3.jpg` (หรือ `01`, `02`…) ก่อนอัปโหลด รูปจะเรียงตามลำดับนี้

### รายการสินค้า
- **ค้นหา** จากรหัสหรือชื่อ ผลกรองทันทีขณะพิมพ์ · **กรองตามหมวดหมู่** ด้วย dropdown ข้างช่องค้นหา (แสดงจำนวนสินค้าในแต่ละหมวด ใช้ร่วมกับการค้นหาได้) · รายการแสดง **20 รายการต่อหน้า** ใช้ปุ่มเลขหน้าหรือลูกศรด้านล่างเพื่อเปลี่ยนหน้า
- **สวิตช์ แสดง/ซ่อน** บนการ์ดสินค้า — กดได้ทันที ไม่ต้องเข้าหน้าแก้ไข สินค้าที่ซ่อนจะจางลง และลิงก์ของสินค้านั้นจะขึ้นว่า "สินค้านี้ไม่พร้อมจำหน่าย" (ถ้าแค่หยุดขาย ให้ใช้สวิตช์นี้ ไม่ต้องลบ)
- **คัดลอกลิงก์** — คัดลอกข้อความ `ชื่อสินค้า` + ลิงก์ พร้อมวางใน LINE (ต้องตั้ง Worker URL ในตั้งค่าก่อน)
- **แก้ไข** — เปิดหน้าแก้ไข (แผงด้านขวาบนจอใหญ่ / เต็มจอบนมือถือ)

### แก้ไขสินค้า
- **Product ID** (เช่น `P000001`) ระบบสร้างให้ แก้ไม่ได้ ใช้เป็นตัวอ้างอิงภายใน
- **รหัสสินค้า** แก้ได้ ถ้าเปลี่ยน **ลิงก์เดิมที่เคยส่งให้ลูกค้าแล้วยังใช้ได้** (ระบบพาไปหน้าใหม่ให้อัตโนมัติ)
- **ลบสินค้า:** ปุ่ม **ลบสินค้า** ท้ายหน้าแก้ไข (มีกล่องให้ยืนยัน) ลบถาวร: สินค้าหายจากรายการ ลิงก์ที่ส่งให้ลูกค้าจะเปิดไม่ได้ (ขึ้น "ไม่พบสินค้า") และโฟลเดอร์รูปที่ระบบสร้างจะถูกย้ายไป**ถังขยะของ Google Drive** (กู้คืนได้ภายใน 30 วัน) ถ้าสินค้านั้นเชื่อมโฟลเดอร์ Drive ที่มีอยู่เดิม โฟลเดอร์นั้นจะไม่ถูกลบ ประวัติการลบ (รหัส ชื่อ ผู้ลบ เวลา) อยู่ใน AuditLog แต่ข้อมูลสินค้าในแท็บ Products จะกู้คืนจากแอปไม่ได้
- **รูปภาพ:** เพิ่มรูป / ลบรูป (ย้ายไปถังขยะของ Google Drive) หรือวางลิงก์โฟลเดอร์ Drive ที่มีรูปอยู่แล้วในช่อง "ใช้โฟลเดอร์ Google Drive ที่มีอยู่แล้ว" แล้วกด **เชื่อม**
- กด **บันทึก** แล้วหน้าร้านจะอัปเดตภายในประมาณ **1 นาที**

### สรุป
การ์ดจำนวนสินค้า **ทั้งหมด / แสดง / ซ่อน** และการ์ดแยกตามหมวด กดการ์ดหมวดเพื่อดูสินค้าในหมวดนั้น

### ตั้งค่า (3 แท็บ)
| แท็บ | ทำอะไรได้ |
|---|---|
| **ร้านค้า** | ชื่อร้าน · โลโก้ (PNG/JPG จัตุรัส) · LINE OA ID · สีหลัก · Worker URL (ล็อกไว้ ต้องกดแก้ไข) · ลิงก์ Google Sheet และลิงก์โฟลเดอร์ Google Drive ของร้าน (ดูอย่างเดียว มีปุ่มคัดลอกและเปิด) |
| **หมวดหมู่สินค้า** | เพิ่ม · เปลี่ยนชื่อ (สินค้าในหมวดเปลี่ยนตามทั้งหมด) · ลบ (ได้เฉพาะหมวดที่ไม่มีสินค้า) |
| **ผู้ใช้งาน** | Admin: ดูรายชื่อ เพิ่ม ลบ ตั้งรหัสผ่านใหม่ให้ผู้อื่น · ทุกคน: เปลี่ยนรหัสผ่านตัวเอง |

ด้านล่างหน้าตั้งค่ามี **"เวอร์ชันระบบ"** (รหัส commit) ใช้ตรวจว่าระบบอัปเดตแล้วหรือยัง

> **Worker URL ถูกล็อกไว้** (แถบสีเทา แก้ไม่ได้) ต้องกดปุ่ม **แก้ไข** ข้างช่องก่อนจึงจะพิมพ์ได้ (กด **ยกเลิก** เพื่อคืนค่าเดิม) และ**เปลี่ยน Worker URL ต้องยืนยันรหัสผ่าน:** เมื่อแก้ช่องนี้ ระบบจะขึ้นคำเตือนสีเหลือง และตอนกดบันทึกจะถามรหัสผ่านของคุณอีกครั้ง (ระบบส่งรหัสลับ `API_SECRET` ไปยังที่อยู่นี้ ถ้าใส่ผิดหรือถูกเปลี่ยนโดยคนอื่นข้อมูลอาจรั่ว) ใส่รหัสผิด 5 ครั้งจะถูกล็อก 15 นาทีเหมือนตอนเข้าสู่ระบบ ถ้าไม่ได้แก้ช่องนี้จะไม่ถามรหัสผ่าน
>
> **Worker URL** ต้องใส่ให้ถูก (`https://npbeauty.ethermorph-corp.workers.dev` / `https://lemonbeauty.ethermorph-corp.workers.dev`) ไม่เช่นนั้นการแก้ไขจะไม่ถูกส่งไปหน้าร้านทันที และปุ่ม "คัดลอกลิงก์" จะใช้ไม่ได้ ระบบตั้งค่านี้และสีหลักให้เป็นค่าเริ่มต้นแล้ว

## 2. นำเข้าสินค้าด้วยไฟล์ CSV

ใช้เมื่อมีสินค้าจำนวนมาก (เมนู **นำเข้า** บนมือถือ หรือ **นำเข้า CSV** บนคอมพิวเตอร์) ไฟล์ตัวอย่างอยู่ที่ [docs/csv-template.csv](docs/csv-template.csv) หรือกดปุ่ม **ดาวน์โหลดไฟล์ตัวอย่าง** ในหน้านั้น

### รูปแบบไฟล์
แถวแรกเป็นหัวตาราง **ต้องเป็นชื่อนี้ตรงตัว**:

```
code,name,category,description,folder_url
```

| คอลัมน์ | ต้องมี | คำอธิบาย |
|---|:-:|---|
| `code` | ✅ | รหัสสินค้า (A-Z a-z 0-9 - _ ไม่เกิน 40 ตัว) ห้ามซ้ำกับสินค้าที่มีอยู่หรือแถวอื่นในไฟล์ |
| `name` | ✅ | ชื่อสินค้า |
| `category` | | ชื่อหมวด ถ้ายังไม่มีในระบบจะสร้างให้ |
| `description` | | รายละเอียด ขึ้นบรรทัดใหม่ได้ถ้าอยู่ในเครื่องหมายคำพูด |
| `folder_url` | | ลิงก์โฟลเดอร์ Google Drive ที่มีรูปอยู่แล้ว ถ้าเว้นว่าง ระบบสร้างโฟลเดอร์เปล่าให้ (อัปโหลดรูปทีหลังในหน้าแก้ไข) |

ข้อความที่มีเครื่องหมายจุลภาค `,` หรือขึ้นบรรทัดใหม่ ให้ใส่ในเครื่องหมายคำพูด `"..."` (Excel ทำให้เองเมื่อบันทึก)

### ต้องบันทึกเป็น **CSV UTF-8**
ใน Excel: **ไฟล์ → บันทึกเป็น → ประเภทไฟล์ → "CSV UTF-8 (Comma delimited)"** ถ้าบันทึกแบบ CSV ธรรมดา ภาษาไทยจะเพี้ยน ระบบจะแจ้งเตือน "กรุณาบันทึกไฟล์เป็น CSV UTF-8" และไม่นำเข้า

### ขั้นตอน
1. เลือกไฟล์ → ระบบแสดง**ตารางตัวอย่าง**พร้อมสถานะของแต่ละแถว:
   - 🟢 **ใหม่** — จะถูกนำเข้า
   - 🟠 **รหัสซ้ำ** — ซ้ำกับสินค้าในระบบหรือซ้ำในไฟล์ (ข้าม)
   - 🔴 **ข้อมูลไม่ครบ** — ไม่มีรหัส/ชื่อ หรือรูปแบบไม่ถูกต้อง (ข้าม)
2. ตรวจแล้วกด **ยืนยันนำเข้า** (ระบบนำเข้าทีละ 50 แถว และสรุปผลให้)
3. นำเข้าแล้วสินค้ายังไม่มีรูป ให้ไปอัปโหลดในหน้าแก้ไข หน้าสินค้าจะขึ้นเมื่อมีคนเปิดลิงก์ครั้งแรก

> การนำเข้า CSV **ไม่ส่งข้อมูลไปหน้าร้านทีละรายการ** (เพื่อไม่ให้ใช้โควตา KV หมด) หน้าร้านจะดึงข้อมูลเองตอนมีคนเปิดลิงก์ครั้งแรก

## 3. ส่งลิงก์ให้ลูกค้าและปุ่มทัก LINE

ลิงก์สินค้าคือ `หน้าร้าน/p/รหัสสินค้า` เช่น `https://npbeauty.ethermorph-corp.workers.dev/p/NP-001` กดปุ่ม **คัดลอกลิงก์** แล้ววางใน LINE เมื่อวางลิงก์ LINE จะแสดง**พรีวิว**รูปปก ชื่อสินค้า และคำอธิบายให้เอง

### ใส่ LINE OA ID (ทำทีหลังได้)
ระหว่างที่ยังไม่ได้ใส่ ปุ่ม "ทัก LINE" ในหน้าสินค้าเป็น**โหมดตัวอย่าง** (กดแล้วแสดงข้อความอธิบายว่าปุ่มจะทำอะไร) เพื่อให้ลูกค้าดูหน้าตาได้ก่อน

1. หา LINE OA ID ในแอป LINE Official Account Manager (ขึ้นต้นด้วย `@` เช่น `@npbeauty`) — ต้องเป็น ID ของ **LINE Official Account** (Basic ID หรือ Premium ID) **ไม่ใช่ LINE ID ส่วนตัว** ถ้าใส่ LINE ID ส่วนตัว ปุ่มจะขึ้น "user not found"
2. หน้า admin → **ตั้งค่า › ร้านค้า** → ช่อง **LINE OA ID** → **บันทึกการตั้งค่าร้าน**
3. ปุ่มกลายเป็นของจริงภายในประมาณ 1 นาที: กดแล้วเปิดแชท LINE ของร้านพร้อมข้อความ `สนใจสินค้า รหัส ชื่อสินค้า`
4. หลังบันทึก ถ้าระบบไม่พบหน้า Official Account ของ ID นั้น จะขึ้นข้อความเตือนสีเหลือง ให้ตรวจ ID อีกครั้ง (ตรวจเองได้โดยเปิด `https://page.line.me/<ID ไม่มี @>` ถ้าเป็น Official Account จะเห็นหน้าโปรไฟล์ของร้าน)
5. **ทดสอบบนมือถือ** กดปุ่มดูว่าเปิดแชทถูกร้านและข้อความขึ้นถูกต้อง

### ส่งให้ลูกค้าทาง Messenger (แชทส่วนตัว)

แชทส่วนตัวของ Messenger เป็นแบบ**เข้ารหัส End-to-End** ซึ่ง**ไม่แสดงรูปพรีวิวของลิงก์** (เป็นข้อจำกัดของ Messenger ไม่ใช่ระบบ — ลิงก์ Apple, GitHub ก็ไม่ขึ้นรูปเช่นกัน) ให้ใช้ปุ่ม **แชร์** แทน:

1. ในหน้า admin บนมือถือ กดปุ่ม **แชร์** (ไอคอนจุดเชื่อม) บนการ์ดสินค้า หรือท้ายหน้าแก้ไขสินค้า
2. ระบบเตรียมรูปปก แล้วขึ้นกล่องแสดงรูป กด **1. แชร์รูป** → เลือก **Messenger** → เลือกคนที่จะส่ง → ส่ง
3. กลับมาที่กล่องเดิม กด **2. แชร์ลิงก์** → เลือก **Messenger** → เลือก**คนเดิม** → ส่ง
4. ลูกค้าจะได้**รูปปก**เป็นรูปภาพ และข้อความ**ชื่อสินค้า + ลิงก์**ต่อกันในแชท (ต้องแยก 2 ขั้น เพราะ Messenger รับรูปพร้อมข้อความในครั้งเดียวไม่ได้ จะส่งไปแค่รูป)

บนคอมพิวเตอร์ส่วนใหญ่แชร์ไฟล์ไม่ได้ กล่องจะมีปุ่ม **บันทึกรูป** และ **คัดลอกข้อความ** ให้แนบเองแทน · ส่งผ่าน **แชทของเพจ Facebook** หรือ **LINE** ลิงก์จะแสดงรูปพรีวิวเองได้ตามปกติ

### ถ้า Facebook Messenger ไม่แสดงรูปพรีวิว

> ถ้าเป็นแชทส่วนตัว (เข้ารหัส) ใช้ปุ่ม **แชร์** ตามหัวข้อด้านบน ขั้นตอนด้านล่างใช้กับแชทของเพจและโพสต์ Facebook

1. เปิด [Sharing Debugger](https://developers.facebook.com/tools/debug/) วางลิงก์สินค้า กด **Debug** แล้วกด **Scrape Again** (ล้างแคชของ Facebook)
2. ถ้าขึ้นเตือนว่าไม่พบ `fb:app_id` ให้สร้าง Facebook App (ฟรี) ที่ developers.facebook.com › My Apps › Create App (ไม่ต้องเผยแพร่แอป) คัดลอก **App ID** ที่เป็นตัวเลข แล้วใส่ใน `worker/wrangler.jsonc` ที่ `vars` → `"FB_APP_ID": "ตัวเลข"` ของแต่ละร้าน (ใช้ App ID เดียวกันได้) แล้ว push ระบบจะเพิ่ม tag ให้ทุกหน้าสินค้า
3. ลิงก์ที่เคยส่งแล้วต้องกด Scrape Again หรือส่งลิงก์ใหม่ (ต่อท้าย `?v=2`) Messenger จึงจะดึงใหม่

### ถ้า LINE ยังโชว์พรีวิวเก่า
LINE จำพรีวิวของลิงก์ไว้ระยะหนึ่ง หากแก้รูปหรือชื่อแล้วลิงก์ที่เคยส่งในแชทเดิมยังโชว์ของเก่า ลองส่งลิงก์ใหม่โดยต่อท้ายด้วย `?v=2` (เช่น `.../p/NP-001?v=2`) ซึ่งมักช่วยให้ LINE ดึงพรีวิวใหม่

## 5. ข้อมูลใน Google Sheet

แต่ละร้านมี Google Sheet ของตัวเอง (`NPBeauty Catalog DB`, `LemonBeauty Catalog DB`) มี 5 แท็บ:

| แท็บ | เก็บอะไร | แก้ด้วยมือได้ไหม |
|---|---|---|
| **Products** | สินค้าทั้งหมด (productId, รหัส, ชื่อ, หมวด, รายละเอียด, โฟลเดอร์รูป, สถานะ, รหัสเก่า ฯลฯ) | ❌ แก้ที่หน้า admin (แก้ใน Sheet โดยตรงไม่ส่งไปหน้าร้านและอาจทำให้ข้อมูลเพี้ยน) |
| **Categories** | รายชื่อหมวดหมู่ | ❌ จัดการที่ ตั้งค่า › หมวดหมู่สินค้า |
| **Settings** | ชื่อร้าน โลโก้ LINE OA ID สีหลัก Worker URL | ❌ แก้ที่ ตั้งค่า › ร้านค้า |
| **Users** | รายชื่อผู้ใช้ (ดูอย่างเดียว) | ❌ ถูกเขียนทับอัตโนมัติ |
| **AuditLog** | ประวัติการแก้ไขทุกครั้ง (เวลา ผู้ใช้ การกระทำ ค่าก่อน/หลัง) เพิ่มต่อท้ายเท่านั้น | ❌ ห้ามแก้หรือลบแถว |

รหัสผ่านและ `API_SECRET` **ไม่ได้เก็บใน Sheet** (เก็บใน Script Properties ของ Apps Script) เมนู **Catalog** ใน Sheet: ตั้งค่าเริ่มต้น · สร้าง/รีเซ็ตผู้ใช้ admin · แสดง API_SECRET · สร้าง API_SECRET ใหม่ · เพิ่ม/ลบข้อมูลตัวอย่าง · ทดสอบระบบ

**ข้อมูลตัวอย่าง:** เมนู Catalog → เพิ่มข้อมูลตัวอย่าง จะเพิ่มสินค้า `DEMO-001` … `DEMO-012` ไว้ลองระบบ ลบทั้งหมดได้ด้วย **ลบข้อมูลตัวอย่าง** (ไม่แตะสินค้าจริง)

**ทดสอบระบบ:** เมนู Catalog → ทดสอบระบบ จะลองสร้าง/แก้/ซ่อนสินค้าชั่วคราว เปิดหน้าร้านจริง ลองนำเข้า CSV และลองล็อกบัญชี แล้วลบข้อมูลทดสอบทิ้งทั้งหมด (ใช้เวลา 1–2 นาที) ผลสรุป 1 บรรทัดอยู่ใน AuditLog (ผู้ใช้ `selftest`) ควรขึ้น `PASS` ทุกข้อ

## 7. ข้อจำกัดของแพ็กเกจฟรี

ระบบใช้บริการฟรีทั้งหมด สำหรับร้านขนาดนี้โดยทั่วไปพอใช้ แต่ควรรู้ขีดจำกัด:

| **Cloudflare Workers** | **100,000 request/วัน** (รีเซ็ตเที่ยงคืน UTC) นับรวมทั้งบัญชี = **2 ร้านใช้ร่วมกัน** | หนึ่งการเปิดหน้าสินค้ามีทั้งหน้าและรูปแต่ละรูปเป็น request (ราว 4–8 ต่อครั้ง) ประมาณ 12,000–25,000 ครั้งเปิดหน้า/วัน ถ้าเกินหน้าร้านจะขึ้นข้อผิดพลาดจนถึงเที่ยงคืน UTC (07:00 น.) |
| **Workers KV — เขียน** | **1,000 ครั้ง/วัน** ต่อบัญชี | **บันทึกสินค้า, สลับแสดง/ซ่อน, อัปโหลดหรือลบรูป แต่ละครั้ง = 1 เขียน** (เพิ่มอีก 1 ต่อรหัสเก่าที่ redirect) · บันทึกตั้งค่าร้าน = 1 · **เปลี่ยนชื่อหมวดเขียนทีละสินค้าในหมวด** · นำเข้า CSV ไม่นับ ถ้าโควตาเต็ม การแก้ไขยังบันทึกใน Sheet ได้ แต่หน้าร้านจะอัปเดตช้า (ภายใน 3 วัน หรือเมื่อบันทึกใหม่หลังรีเซ็ต) |

| **Google Drive** | 15 GB ต่อบัญชี (ใช้ร่วมกับ Gmail/Photos) | ระบบย่อรูป ≈ 200–500 KB ต่อรูป เก็บได้ราวหลายหมื่นรูป |

## 8. สำหรับผู้ดูแลระบบ

ส่วนนี้สำหรับคนดูแลโค้ดและบัญชี (ผู้ใช้ร้านทั่วไปไม่ต้องอ่าน) สเปกและเหตุผลการออกแบบอยู่ใน [CLAUDE.md](CLAUDE.md) แผนและสถานะงานอยู่ใน [PLAN.md](PLAN.md) / [WORKPLAN.md](WORKPLAN.md)

### โครงสร้างโดยย่อ
```
ลูกค้า → Cloudflare Worker (หน้าสินค้า /p/รหัส, รูป /img, รับ sync) ← KV
                  ↕ API_SECRET
แอดมิน → Google Apps Script (หน้า admin + JSON API) → Google Sheet + Google Drive
```
- **2 ร้านแยกระบบกัน** (Sheet, Apps Script, Drive, Worker, KV, secret, ผู้ใช้) แต่ใช้โค้ดชุดเดียวใน repo นี้ รายชื่อร้านอยู่ใน [shops.json](shops.json)
- โค้ดหลังบ้าน `gas/` · หน้าร้าน `worker/` · ทดสอบ `tests/` · workflow `.github/workflows/`

### อัปเดตโค้ด
แก้ไฟล์ใน repo แล้ว push เข้า `main` ระบบ deploy ให้เอง:

| ส่วน | ใครทำ | ผล |
|---|---|---|
| **หน้าร้าน** (`worker/`) | Cloudflare Workers Builds (เชื่อมกับ repo แล้ว) | build + deploy ทั้ง 2 ร้านภายในประมาณ 1 นาที |
| **หลังบ้าน** (`gas/`) | GitHub Actions `Deploy GAS` | รันชุดทดสอบ → push + อัปเดต deployment **เดิม** ทั้ง 2 ร้าน (ลิงก์ `/exec` ไม่เปลี่ยน) ถ้าทดสอบไม่ผ่านจะไม่ deploy |

ดูผลที่แท็บ Actions ของ repo และตรวจ "เวอร์ชันระบบ" ในหน้า admin ว่าตรงกับ commit ล่าสุด

คำสั่งที่ใช้บ่อย (ในโฟลเดอร์โปรเจกต์ ต้องมี Node.js 20+):
```bash
npm run test:gas                       # ทดสอบหลังบ้านบน mock (ไม่ต้องใช้บัญชี Google) — รันก่อน push ทุกครั้ง
npm run preview:admin                  # เปิดหน้า admin จริงที่ http://localhost:8787 กับข้อมูลทดสอบ
npm run gas -- <npbeauty|lemonbeauty|all> push                 # ส่งโค้ดขึ้น Apps Script (ปกติให้ Actions ทำ)
npm run gas -- <shop|all> deploy "ข้อความ"                      # อัปเดต deployment เดิม
npm run gas -- all deployments                                  # ดูรายการ deployment
cd worker && npm run dev:preview       # รัน Worker ในเครื่องกับ GAS จำลอง (เปิด preview:admin ก่อน)
```
เรียก clasp ผ่าน `npm run gas --` เสมอ (สคริปต์เลือก Script ID ถูกร้านและใส่ค่าเริ่มต้นประจำร้านให้) ห้ามรัน `clasp` ตรงๆ ใน `gas/`

### Secret และบัญชีที่เกี่ยวข้อง
| อะไร | อยู่ที่ไหน | หมายเหตุ |
|---|---|---|
| `API_SECRET` ของแต่ละร้าน | Script Properties (Apps Script) **และ** secret ของ Worker ร้านเดียวกัน | ต้องเป็นค่าเดียวกัน แยกกันคนละร้าน |
| รหัสผ่านผู้ใช้ | Script Properties (`USERS` เก็บเป็น salted hash) | ไม่อยู่ใน Sheet |
| `CLASPRC_JSON` | GitHub → Settings → Secrets → Actions | ให้ Actions ใช้ clasp แทนบัญชี ethermorph.corp |

#### เปลี่ยน API_SECRET
ทำเมื่อสงสัยว่ารั่ว หรือเปลี่ยนคนดูแล ทำ**ทีละร้าน** และทำขั้น 1–2 ให้ต่อเนื่องกันเพราะระหว่างนั้นหน้าร้านที่ยังไม่มีข้อมูลในแคชจะขึ้น 503:
1. เปิด Google Sheet ของร้านนั้น → **Catalog → สร้าง API_SECRET ใหม่** → ยืนยัน → คัดลอกค่าที่แสดง
2. ตั้งค่าเดียวกันที่ Worker ของร้านเดียวกัน — เลือกอย่างใดอย่างหนึ่ง:
   - Cloudflare dashboard → Workers & Pages → (npbeauty / lemonbeauty) → Settings → **Variables and Secrets** → `API_SECRET` → Edit → วางค่าใหม่ → Deploy
   - หรือรัน `cd worker && npx wrangler secret put API_SECRET --env <npbeauty|lemonbeauty>` แล้ววางค่าในเทอร์มินัล
3. ตรวจ: เปิดลิงก์หน้าสินค้าของร้านนั้น และรัน Catalog → ทดสอบระบบ ควรได้ `PASS` (รูปบนหน้าที่แคชไว้อาจเปิดไม่ได้อยู่ประมาณ 1 นาที เพราะลิงก์รูปเซ็นด้วย secret เดิม)

⚠️ ห้ามนำค่าไปวางในแชท / issue / commit และห้ามใช้ค่าของร้านหนึ่งกับอีกร้าน

#### Actions ขึ้นสีแดง "authentication/clasp"
token ของ clasp หมดอายุหรือถูกเพิกถอน (เช่น เปลี่ยนรหัสผ่านบัญชี Google) แก้โดย: `npx clasp login` (บัญชี ethermorph.corp) แล้วตั้ง secret ใหม่ด้วย PowerShell:
```powershell
Get-Content "$HOME\.clasprc.json" -Raw | gh secret set CLASPRC_JSON --repo ethermorphcorp-cloud/Beauty-Catalog
```
(อย่าใช้ `--body "$(cat ...)"` บน PowerShell เพราะเครื่องหมาย `"` ใน JSON จะหาย) แล้วกด Re-run ใน Actions

### เพิ่มร้านใหม่
1. สร้าง Google Sheet + Apps Script ใหม่ และโฟลเดอร์ Drive ของร้าน
2. เพิ่มร้านใน `shops.json` (scriptId, rootFolderId, defaults) และ env ใหม่ใน `worker/wrangler.jsonc`
3. `npm run gas -- <shop> push` → ในเมนู Sheet รัน ตั้งค่าเริ่มต้น + สร้างผู้ใช้ admin → Deploy ครั้งแรกด้วย **New deployment** (ครั้งเดียว) → ใส่ deploymentId ใน `shops.json`
4. สร้าง KV, deploy Worker, ตั้ง `API_SECRET`, เชื่อม Workers Builds ตามหัวข้อ 1–6 ของ [PLAN.md](PLAN.md)

### ส่งมอบร้านให้ลูกค้าเป็นเจ้าของ (เปลี่ยนโฟลเดอร์รูปและบัญชีที่รัน)
โฟลเดอร์ Drive ของ Gmail ส่วนตัวโอนเจ้าของไม่ได้ จึงให้ลูกค้าสร้างโฟลเดอร์ใหม่ รูปเดิมไม่ถูกย้าย (สินค้าที่มีรูปต้องอัปโหลดใหม่หรือวางลิงก์โฟลเดอร์ใหม่)
1. ลูกค้าสร้างโฟลเดอร์ใหม่ใน Drive ของตัวเอง แล้วคัดลอกลิงก์
2. โอนเจ้าของ Google Sheet ให้ลูกค้า (Script ที่ผูกกับ Sheet ไปด้วย) และเพิ่มผู้ดูแลเป็น Editor ถ้ายังต้อง push โค้ด
3. ลูกค้าเปิด Sheet ไปแท็บ **Settings** วางลิงก์ใหม่ในแถว `rootFolderUrl` (ถ้าไม่มีแถวนี้ ให้รันตั้งค่าเริ่มต้นหนึ่งครั้งก่อน)
4. ลูกค้ารัน **Catalog → ตั้งค่าเริ่มต้น** และกดอนุญาตสิทธิ์ด้วยบัญชีตัวเอง ระบบจะสลับโฟลเดอร์หลักตามลิงก์ใน Settings
5. ลูกค้าไปที่ Apps Script → Deploy → **Manage deployments** → แก้ deployment เดิม (Execute as **Me**) → New version แล้วตรวจว่า URL `/exec` ยังเหมือนเดิม ถ้าเปลี่ยนต้องแก้ `GAS_URL` ใน `wrangler.jsonc` กับ `shops.json` แล้ว deploy Worker ใหม่
6. ตรวจ `API_SECRET` ใน Script Properties ให้ตรงกับ secret ของ Worker แล้วรัน Catalog → ทดสอบระบบ

## 9. สิ่งที่ห้ามทำ

1. ❌ **ห้ามกด "New deployment" ใน Apps Script** (ยกเว้นตอนตั้งร้านใหม่ครั้งแรก) URL `/exec` จะเปลี่ยนและหน้าร้านจะใช้ไม่ได้ อัปเดตด้วย `npm run gas -- <shop> deploy` หรือปล่อยให้ GitHub Actions ทำ
2. ❌ **ห้ามแก้โค้ดใน Apps Script editor บนเว็บ** — การ push รอบถัดไปจะเขียนทับ ให้แก้ใน repo เท่านั้น
3. ❌ **ห้ามวาง `API_SECRET`, รหัสผ่าน หรือไฟล์ `.clasprc.json` ในแชท, ใน issue หรือ commit ลง repo** (`.gitignore` กันไฟล์ที่เกี่ยวข้องไว้แล้ว)
4. ❌ **ห้ามแก้หรือลบแถวใน AuditLog** และไม่ควรแก้แท็บ Products / Categories / Settings / Users ด้วยมือ
5. ❌ **ห้ามย้ายหรือเปลี่ยนเจ้าของโฟลเดอร์รูปใน Drive** (ถ้าต้องเปลี่ยนจริง ดูหัวข้อ "ส่งมอบร้านให้ลูกค้า") หรือลบแท็บของระบบใน Sheet (ถ้าลบ ให้รัน Catalog → ตั้งค่าเริ่มต้นเพื่อสร้างใหม่ ข้อมูลเดิมไม่หาย)
6. ❌ **ห้ามใช้ `API_SECRET` ร่วมกันสองร้าน** และห้าม deploy Worker โดยไม่ใส่ `--env <ร้าน>`
7. ⚠️ ลบสินค้าเฉพาะที่ไม่ใช้แล้วจริงๆ — ถ้าแค่หยุดขาย ใช้สวิตช์ **ซ่อน** แทน เพื่อให้ลิงก์ที่เคยส่งแล้วขึ้นข้อความ "ไม่พร้อมจำหน่าย" ไม่ใช่ "ไม่พบสินค้า"
